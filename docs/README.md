# Índice documental

| Área | Documento | Uso |
|---|---|---|
| Intenção | `design/GDD.md` | Regras e conceito originais |
| Produto | `vision/VISION.md` | Proposta e fronteiras |
| Requisitos | `requirements/REQUIREMENTS.md` | IDs RF/RNF, prioridades, aceites |
| Specifications | `specifications/SPEC-*.md` | Comportamento por feature |
| Arquitetura | `architecture/OVERVIEW.md`, `CONTRACTS.md`, `SIMULATION-SEMANTICS.md` | Implementação coerente |
| Design | `ux/`, `levels/` | UX, composição e progressão |
| QA | `qa/` | Provas de aceite |
| Execução | `roadmap/`, `reports/` | Gates, prompts e evidências |
| Publicação | `release/` | Checklist legal e itch.io |

**Processo de mudança:** pedido → especificação/requisito → decisão/ADR (se necessário) → código/teste → evidência/relatório → atualização de rastreabilidade.
