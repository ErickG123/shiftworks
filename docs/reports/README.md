# Relatórios de execução

Esta pasta começa vazia por design. Não existem fases concluídas apenas porque a documentação foi criada.

Padrão: `REPORT-PHASE-XX-<slug>.md`, alimentado a partir de `docs/templates/PHASE-REPORT-TEMPLATE.md`.

O relatório da etapa XX é leitura obrigatória pela etapa XX+1. Desvios de requisitos/contratos exigem ADR ou decisão explícita e atualização da rastreabilidade. Nunca copiar logs inventados.
