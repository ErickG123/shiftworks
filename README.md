# SHIFTWORKS

SHIFTWORKS is a browser based automation puzzle about small factories that change how they work. It is being developed for GitHub Game Off 2026 and the theme **SHIFT**.

## Project status

The project includes an isometric factory editor, deterministic simulation, three Campaign levels, progression/scoring, and a free Sandbox using the same engine. The implementation is in progress; browser E2E and visual gates remain incomplete in this environment. See the phase reports and `docs/roadmap/ROADMAP.md` for verified status.

## Controls

- Choose a build tool, then left-click an empty board cell to place a component. Use Select to inspect/configure, or Remove and click a component to return it to inventory.
- Select a movable component and use Rotate or `R`. `Escape` cancels the current build tool.
- Use Start, Pause, Resume, Edit, Reset, Replay and Next level buttons. When the board has focus, `Space` starts, pauses, or resumes.
- Zoom with the mouse wheel over the board or the `-`, `100%`, and `+` controls. Panels scroll normally.
- In Sandbox, select a source sequence, clear the layout, or load the example.

## Requirements

- Node.js 22.12 or newer
- npm 10 or newer

## Development

```sh
npm ci
npm run dev
```

Open Campaign to play the three guided levels. Choose Sandbox to experiment with unlimited components, switch the Source between blue, amber, and alternating items, clear the board, or reload the example. Campaign progress and preferences save locally when browser storage is available; gameplay continues with session-only state when it is blocked.

## Quality checks

```sh
npm run lint
npm run typecheck
npm run test
npm run test:fixtures
npm run build
npm run preview
npm run test:e2e
```

The production build is written to `dist/` and can be hosted as a static site. There is no backend, account system, or required network connection during gameplay.

## Technology and attribution

- Vite and TypeScript for the web application.
- Three.js for browser 3D rendering.
- Vitest and jsdom for automated foundation and game-domain tests.
- Factory geometry and sound effects are generated by project code; no external art, model, font, or audio files are bundled.
- AI-assisted development was used for code and documentation. No AI-generated artwork, models, or audio assets are included. The Game Off submission asks participants to disclose AI use.

Dependency versions are resolved by `package-lock.json`; run `npm run audit:licenses` to review license metadata recorded for the locked dependency tree and verify package manifests are installed. The repository license is MIT; see `LICENSE`.
